## 1. Stat cards (github-readme-stats)

⚠️ **Read this first.** The public `github-readme-stats.vercel.app` instance shares a single
5,000 req/hour GitHub API budget across everyone using it, so cards intermittently render as
"Maximum retries exceeded" or just break. If you want these, deploy your own Vercel instance
(takes ~5 minutes) and swap the host. Otherwise skip them — they're also the single most common
"generic profile" tell.

```html
<div align="center">
  <img height="150" src="https://github-readme-stats.vercel.app/api?username=iurman&show_icons=true&hide_border=true&bg_color=040403&title_color=89AAE6&icon_color=32746D&text_color=b8bab2&ring_color=FFC4D1" alt="Isaac's GitHub stats">
  <img height="150" src="https://github-readme-stats.vercel.app/api/top-langs/?username=iurman&layout=compact&hide_border=true&bg_color=040403&title_color=89AAE6&text_color=b8bab2" alt="Top languages">
</div>
```

Colors above are already set to your portfolio palette (`#040403` void, `#89AAE6` electric,
`#32746D` accent, `#b8bab2` secondary text, `#FFC4D1` ember).

## 2. Contribution snake

Reliable, because the SVG is generated by *your own* GitHub Action and committed to your repo —
nothing external to rate-limit. Requires adding a workflow.

`.github/workflows/snake.yml`:

```yaml
name: generate snake
on:
  schedule: [{ cron: "0 6 * * *" }]
  workflow_dispatch:
permissions:
  contents: write
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        id: snake
        with:
          github_user_name: iurman
          outputs: |
            dist/snake.svg?palette=github-dark&color_snake=#89AAE6&color_dots=#040403,#285e58,#32746D,#3d8a82,#89AAE6
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Then in the README:

```html
<div align="center">
  <img src="https://raw.githubusercontent.com/iurman/iurman/output/snake.svg" alt="Contribution snake" width="100%">
</div>
```

## 8. Things worth *not* doing

Based on what makes profiles look templated rather than authored:

- **Profile-view counters** — reads as vanity metrics, and the number is meaningless.
- **Trophy walls** (`github-profile-trophy`) — decorative, says nothing a recruiter can use.
- **Streak counters** — rewards obsessive commit behavior, and breaks when the host is down.
- **A wall of `<img>` skill icons** — see block 5.
- **`Hi 👋 I'm X`** — every generated profile opens this way. A banner or a claim reads better.
- **Emoji bullet lists** (`🔭 🌱 👯 💬 ⚡`) — that's the literal GitHub default template.

Your old README had three of these. The variants drop them on purpose.
